# 绿色消费凭证争议台

本项目提供绿色消费凭证争议台的领域事件交换约定、基础校验库与核心争议处理服务。接入方使用统一的聚合标识、事件版本和带时区的发生时间，保证业务事实在不同环节之间可以复核。

## 目录

- `contracts/domain.schema.json`：领域事件信封和已登记类型。
- `data/sample.json`：中文联调样例。
- `src/green_consumption_claims/contracts.py`：不依赖第三方包的基础校验器。
- `src/green_consumption_claims/models.py`：凭证分级、案件状态、绿色品类等词汇与异常。
- `src/green_consumption_claims/store.py`：本机 JSON 快照持久化（原子替换）。
- `src/green_consumption_claims/service.py`：争议台核心服务 `DisputeDesk`。
- `tests/test_contracts.py`：契约边界检查。
- `tests/test_service.py`：争议处理流程检查。

## 核心服务能力

- **版本化承诺**：商家承诺按版本登记，版本单调递增、不可改写；下架只标记时间，承诺原文保留可查；退款或改签只追加订单变更历史，不抹掉原承诺。
- **规则版本**：绿色行动认定规则按版本生效，立案时锁定当时生效的版本，规则更新只用于新案件。
- **订单评估**：一次订单可含餐饮、礼盒、出行、回收等多个部分，只有符合对应规则的部分计入绿色行动；退款部分保留"原承诺"事实但不再计入当前行动。
- **凭证受理**：凭证按上传方分为事实材料、商家自证、调解结论；订单类凭证必须经消费者授权；同一凭证重复上传返回既有受理回执，内容冲突冻结争议而不是任选一份；商家不能改写消费者原始凭证。
- **隐私最小化**：调解员视图中消费者以化名出现，联系方式脱敏。
- **期限与恢复**：所有状态即时落盘，平台重启后已保存的受理与期限继续计时；补救通知进入 outbox，外部投诉渠道不可用时滞留待发、恢复后补发。
- **可回溯**：`case_report` 说明每项主张采用的承诺版本与规则版本、经手人轨迹，以及是否形成可执行的补偿或整改。
